Kitchen Storage Planner

For kitchen designers and home owners. List what needs to be stored in the dry and wet kitchen, enter the cabinet widths you have, and get a suggested place for everything, with the reason, and the questions to ask before cabinets are made.

Step 1 · optional

Paste the client's notes

Rough is fine: typos, slashes, "5kg- max 20kg". The AI only tidies them into a list. It does not decide where anything goes.

Demo mode: this is the pre-made list for the example notes. It doesn't read what you type. You can still edit the list below, and the plan updates as you change it.
Step 2

Check the list and cabinet widths

Widths are in millimetres, one number per base cabinet, separated by commas. Changes update the plan straight away.

The example uses sample cabinet widths, not measurements. Replace them with the real ones.
A portfolio demo. Suggestions only: a kitchen designer must confirm sizes, loads and appliance specifications before anything is made. Blum product names are given as examples of each fitting type. This project is not connected to Blum.
